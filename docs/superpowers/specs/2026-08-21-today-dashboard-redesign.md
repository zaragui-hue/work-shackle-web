# Work Shackle 今日页潮流化重设计

> 状态：已评审（对话确认整体布局、提醒交互、文案方向与打工马角色）  
> 日期：2026-08-21  
> 范围：今日页信息架构、视觉语言、班表提醒、进度叙事与半写实打工马

## 1. 目标

将当前偏温和、偏通用工具的今日页改造成一张有明确性格的「打工人生存仪表盘」。它要同时做到：

1. 用户打开页面后，一眼看清距下班还有多久、今天处于什么精神状态。
2. 今日任务是主要工作区，拥有足够高度和清晰操作层级。
3. 用户可以临时修改今天的下班时间，并设置上班过程中的自嘲式提醒。
4. 进度反馈不做传统企业仪表盘，而是由一匹朝下班奔跑的马承担叙事。
5. 幽默建立在真实使用场景上，不牺牲可读性、状态准确性或操作效率。

一句话定位：**它不是催你提高效率，而是陪你体面地熬到下班。**

## 2. 已确认决策

| 项目 | 决策 |
|---|---|
| 总体方向 | C「精神状态事务所」 |
| 表情处理 | 借鉴 B「工位续命」的贴纸式情绪表达，但控制数量 |
| 首屏结构 | 倒计时、状态和进度合并为紧凑舞台；阶段文案独立放在右侧 |
| 卡片位置 | 左上倒计时舞台；右上阶段文案；左下加高任务现场；右下自定义班表 |
| 默认下班时间 | 18:00，可修改当天时间 |
| 状态提醒 | 到点提示，由用户确认是否切换；不自动篡改工作状态 |
| 进度角色 | 一匹朝右奔跑的半写实潮流插画马 |
| 马的笔触 | B「墨线块面半写实」 |
| 动效原则 | 马的四肢真实奔跑，卡片和整个图标不整体弹跳 |

## 3. 视觉语言

### 3.1 气质

受控的新粗野主义与潮流杂志编排：高对比、粗描边、醒目标题、局部荧光色、不完全规则的进度轨道。视觉可以叛逆，但信息结构必须稳定。

关键词：

- 工位生存感
- 潮流编辑感
- 克制 Meme
- 局部手绘
- 硬朗外框与轻松文案的反差

禁止：

- OA、Jira 或通用 SaaS 仪表盘感
- 大量渐变玻璃、悬浮光晕和科技蓝
- 表情包堆满页面
- 夸张大头卡通马
- 写实照片直接贴进界面
- 所有卡片持续摇晃或弹跳

### 3.2 配色

基于当前重设计中的颜色统一为：

| 角色 | 建议值 | 用途 |
|---|---|---|
| 纸张底色 | `#F4F0E7` | 页面背景、浅色卡片 |
| 墨黑 | `#171717` | 正文、粗描边、深色卡片 |
| 电光蓝 | `#376CFF` | 状态、链接、阶段信息 |
| 荧光绿 | `#DFFF48` | 下班目标、成功、主要进度高光 |
| 提神橙 | `#FF7438` | 警示、插活、重要提醒 |
| 次级灰 | `#69665F` | 辅助说明 |

颜色使用规则：同一块卡片最多一个主强调色；荧光绿只奖励与下班、完成有关的时刻；橙色只提示打断、临时任务或需要注意的状态。

### 3.3 字体与形状

- 中文继续使用系统无衬线字体栈，避免在线字体依赖。
- 数字倒计时使用紧凑、粗重字形，保持最高视觉优先级。
- 卡片使用 2px 左右深色描边和 16–24px 圆角；不做过分圆润的儿童化胶囊。
- 允许轻微错位阴影、倾斜标签与手写批注，但正文不可倾斜。
- 贴纸元素只出现在阶段文案、提醒和完成反馈中。

## 4. 页面信息架构

桌面宽度采用两列网格。左列略宽，用于倒计时与任务；右列用于阶段叙事和班表设置。

```text
┌────────────────────────────┬──────────────────────┐
│ 距离下班 / 当前状态 / 奔跑马 │ 当前阶段文案与打气提示 │
├────────────────────────────┼──────────────────────┤
│                            │                      │
│ 今日任务现场（加高主工作区） │ 今日自定义班表与提醒     │
│                            │                      │
└────────────────────────────┴──────────────────────┘
```

移动端按以下顺序单列排列：倒计时舞台 → 阶段文案 → 今日任务 → 自定义班表。

### 4.1 左上：下班倒计时舞台

包含：

- 距离下班的主要倒计时。
- 当前精神状态和快捷切换入口。
- 当前工作进度百分比。
- 不规则、略带手绘感的进度轨道。
- 沿轨道向右奔跑的打工马。
- 轨道终点「下班」标记。

该区域必须紧凑，不再占据整行或使用过大的吉祥物。它的任务是回答“还要熬多久”，而不是展示装饰。

### 4.2 右上：阶段文案

展示当前阶段的一条主文案和一条辅助提示。文案按进度和工作状态切换，不每秒变化，避免干扰。

建议阶段矩阵：

| 进度 | 主文案 | 辅助文案 |
|---|---|---|
| 0–25% | 今天也算顺利开机了 | 先别燃烧，上午还长 |
| 25–55% | 已进入稳定耗电区 | 保持呼吸，工资按天算 |
| 55–80% | 下班已经有了具体形状 | 再顶一下，别在这里交代 |
| 80–99% | 终点就在打印机后面 | 别在终点前接新活 |
| 100% | 今日工位使用权已到期 | 谁叫你都听不见 |

特殊状态优先于普通进度文案，例如午休、加班、已下班、任务错误。

### 4.3 左下：今日任务现场

这是首屏主工作区，垂直空间应明显高于其他卡片。内容层级：

1. 当前进行中的正式任务。
2. 临近截止任务。
3. 逾期与临时插活。
4. 今日已完成任务，可折叠或降低视觉权重。

主要动作保持明确：新建任务、查看详情、完成、延期。幽默文案用于空状态、分组标签和结果反馈，不改写关键动作名称。

空状态示例：

- 「暂时没人往你工位扔活」
- 「看起来很清闲，建议保持低调」

### 4.4 右下：今日自定义班表

班表卡片包含：

- 今日下班时间，默认 18:00。
- 小时与分钟选择，修改后即时更新倒计时。
- 当天临时覆盖与长期默认时间的清晰区别。
- 提醒列表：时间、提醒类型、文案、是否启用、编辑与删除。
- 快速添加提醒。

初始推荐提醒：

| 时间 | 类型 | 提示 |
|---|---|---|
| 10:30 | 喝水 | 杯子还在，水呢？ |
| 12:00 | 午休 | 先把人类基础需求处理一下 |
| 15:00 | 续命 | 咖啡可以续，命别全押上 |
| 17:30 | 收尾 | 现在接的新活，明天也不会消失 |

提醒是可编辑的建议值，不强制写入。用户可以设置提醒时间、提醒文案以及建议切换到的状态。

## 5. 提醒交互

### 5.1 到点行为

到达提醒时间后：

1. 在应用内显示轻量提醒层；桌面提醒能力可继续复用现有窗口机制。
2. 展示自嘲文案、建议状态和两个明确动作。
3. 用户点击「切换状态」后才写入新状态。
4. 用户点击「先这样吧」后仅关闭本次提醒。
5. 同一提醒在当天不重复弹出，除非用户主动设置稍后提醒。

不允许仅因时间到达就自动改变状态，避免工作记录与真实情况不一致。

### 5.2 编辑反馈

- 修改下班时间后，倒计时、进度百分比和阶段文案立即重新计算。
- 保存期间禁用重复提交，并提供不跳布局的加载反馈。
- 无效时间、保存失败使用直接语言说明，幽默文案不得遮蔽错误原因。
- 若下班时间早于当前时间，进入已下班判断流程，而不是显示负数。

## 6. 半写实打工马

### 6.1 角色造型

- 栗棕色成年马，真实马头、躯干与四肢比例。
- 黑色鬃毛与尾巴，墨线轮廓带轻微手绘抖动。
- 阴影以深蓝、灰棕块面表达，少量荧光绿用于进度反光。
- 不穿整套拟人服装，不使用大眼、大头和短肢比例。
- 情绪由耳朵、眼神、嘴角、鬃毛状态表达。

### 6.2 奔跑动画

- 方向始终朝右，终点为下班。
- 使用六帧左右的奔跑循环或等效骨骼/矢量动画。
- 前后腿必须真实交替发力，包含腾空与落地阶段。
- 鬃毛和尾巴比躯干晚半拍摆动。
- 躯干只做符合步态的小幅重心变化，不允许整个容器同步上下弹跳。
- 进度位置由工作时段百分比控制；奔跑循环只表达运动，不改变进度位置。
- 支持 `prefers-reduced-motion`：关闭循环跑动，保留静态姿势与进度位置。

### 6.3 进度神态

| 进度 | 耳朵与眼神 | 嘴角与鬃毛 |
|---|---|---|
| 0–25% | 耳朵向前，眼神清醒 | 嘴角自然，鬃毛整齐 |
| 25–55% | 半眯眼，开始省电 | 嘴角平直 |
| 55–80% | 眼神疲惫，耳朵略后 | 嘴角下沉，鬃毛凌乱 |
| 80–99% | 耳朵重新竖起，目光看向终点 | 轻微用力表情 |
| 100% | 停步并回头 | 松弛、对呼叫无反应 |

角色在界面中保持 48–72px 左右的视觉尺寸，具体随轨道和响应式布局调整，不占用任务区空间。

## 7. 状态与优先级

今日页主舞台需覆盖：

- 加载中
- 正常工作时段
- 午休或其他工作状态
- 下班待确认
- 正常下班完成
- 加班进行中
- 设置或数据加载失败

优先级从高到低：错误/待处理决定 → 加班/已下班 → 特殊工作状态 → 普通进度文案。

无数据时不能出现空白大卡片，应显示明确空状态和可执行动作。

## 8. 可访问性与性能

- 文字与背景保持 WCAG AA 所需对比度。
- 马匹动画为装饰时使用适当的无障碍隐藏；进度仍由文本和原生进度语义表达。
- 所有时间选择、提醒开关和操作按钮可用键盘访问，并具有可理解的标签。
- 不依赖网络图片、在线字体或运行时 CDN。
- 马匹素材作为本地原创 SVG/序列帧提供，避免加载抖动。
- 动画优先使用 `transform` 和 `opacity`，避免频繁触发布局。

## 9. 实现边界

本轮包含：

- 今日页两列布局与响应式调整。
- 倒计时、状态和进度舞台整合。
- 阶段文案规则。
- 任务区视觉层级与高度调整。
- 今日下班时间编辑。
- 今日提醒列表、创建/编辑/启用/删除及到点提示。
- 原创半写实马素材、奔跑动画与五段神态。
- 相关单元测试、构建检查与真实页面视觉验收。

本轮不包含：

- 社交分享或真实表情包下载。
- 复杂游戏化积分、排行榜或成就系统。
- 第三方在线素材和受保护 IP。
- 与本次今日页无关的任务业务重写。

## 10. 验收标准

1. 首屏符合已确认的四区布局，左上区域不再夸张占位，任务区明显加高。
2. 默认 18:00 下班，修改后倒计时、进度、马的位置与文案同步刷新。
3. 进度轨道具有不规则视觉，马始终朝右，只有马本身在跑。
4. 马保持真实结构和墨线块面质感，五个进度阶段具有可识别但不过度夸张的神态。
5. 提醒到点后不会自动切换状态，只有用户确认后才更新。
6. 页面文案有打工人自嘲感，但主要动作与错误信息保持明确。
7. 桌面和窄屏布局均无重叠、截断或水平滚动。
8. `prefers-reduced-motion` 下无持续跑动。
9. 前端测试与构建通过，并完成本地页面视觉检查。
