# 倒计时面板桌面端高度缩减设计

## 背景

“距离下班还有”倒计时与右侧“精神状态”已采用并列、等高的 Split Layout。当前桌面端顶部双栏最小高度约为 390px，占用首屏空间偏多。

## 目标

- 桌面端顶部双栏整体高度缩减四分之一，由约 390px 调整为约 293px。
- 蓝色倒计时与橙色精神状态面板继续保持并列、等高。
- 内容随容器同步收紧，避免文字、进度条、插画或状态说明被裁切。
- 手机端布局与尺寸保持不变。

## 设计方案

采用“容器与内容同步压缩”的方式：在桌面端同时降低左右面板和倒计时主体的最小高度，并相应收紧内部间距、倒计时字号、进度区域与右侧插画尺寸。避免使用裁切或 CSS 整体缩放，以保持文字清晰和布局稳定。

### 蓝色倒计时面板

- 外层最小高度从 390px 调整为 293px。
- 倒计时主体最小高度从 360px 调整为约 270px。
- 缩小标题、数字区域和进度区域之间的垂直空隙。
- 适度下调超大倒计时数字与标题的桌面端字号，保留原有视觉层级。
- 进度条仍固定在面板底部视觉区，不遮挡文字。

### 橙色精神状态面板

- 外层最小高度同步从 390px 调整为 293px。
- 插画主视觉高度按新空间收紧，状态标签和说明卡保持完整可读。
- 减少上下留白，保持右侧信息密度与蓝色面板协调。

### 响应式边界

- 高度调整仅应用于桌面端。
- 现有移动端媒体查询继续使用原尺寸，不因桌面端调整而缩短。

## 验收标准

- 桌面端左右面板的可见高度约为原来的 75%，且仍然严格等高。
- 两侧内容均无裁切、溢出或重叠。
- 主视觉、倒计时、进度条、状态标签和说明文字均保持清晰。
- 手机端视觉高度和布局无变化。
- 相关前端测试与生产构建通过。
