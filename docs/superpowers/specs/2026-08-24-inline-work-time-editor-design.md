# 今日页批注微调设计

## 目标

根据今日页的六条页面批注，减少重复信息，让下班时间直接可操作，同时修正任务状态和打工马进度区域的视觉遮挡。

## 已确认方案

采用“大数字原位编辑”：工位控制台中的大号下班时间本身就是 `time` 输入控件。用户点击大数字后直接选择时间；值变化后立即沿用现有排班保存流程，不增加确认按钮或第二行小时、分钟控件。

保存采用乐观反馈：界面立即显示新时间并进入保存状态。保存成功后同步最新排班；保存失败时恢复到当前有效时间，并在控件下方显示可读错误，同时保留键盘操作和明确的无障碍标签。

## 版式调整

- 删除工位控制台中独立的小时、分钟选择行及重复的“改完即生效”说明。
- 删除倒计时进度条上方的开工、下班时间点；终点“下班”贴纸继续承担方向提示。
- 将“班味百分比”放大并改为黑底黄字、红色投影，使它与蓝色舞台形成更强反差。
- 将打工马的单字心情气泡移到马身后上方，避开马头和奔跑方向。
- 即将到点任务卡中的优先级状态解释靠右放置；其他任务信息结构保持不变。

## 边界

- 不改变默认排班与今日临时排班的业务规则。
- 不增加新的弹层、自定义时钟或保存按钮。
- 不修改任务优先级、倒计时和工作进度的计算逻辑。
- 桌面端与手机端均不得产生横向溢出。

## 验证

- 组件测试覆盖原位时间输入、即时保存、保存失败回退，以及已删除的冗余控件。
- 现有倒计时、任务卡和排班测试继续通过。
- 在桌面与 390px 手机视口检查布局、点击区域、马头遮挡和状态右对齐。
