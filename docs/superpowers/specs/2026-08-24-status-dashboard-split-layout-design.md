# 精神状态 Dashboard 分栏布局设计

## 目标

将今日页顶部的蓝色倒计时区域和橙色精神状态区域重构为两个并列、同级、互不遮挡的信息 Panel，形成清晰的 Dashboard Split Layout。

## 视觉方向

以用户确认的参考截图为准：桌面端使用横向大卡结构，蓝色倒计时约占 68%，橙色精神状态约占 32%。两块区域等高并列，共享一致的顶部与底部基线，由明确的粗边框和间隙分隔。

蓝色区域保持主视觉地位，承载倒计时标题、巨大时间数字、工作进度与奔跑吉祥物。橙色区域成为完整独立的精神状态 Panel，承载当前状态控件、巨型情绪字、吉祥物与状态文案。

## 组件结构

### 页面容器

`TodayPage` 继续使用顶部 `today-page__stage` 作为布局入口，但该容器不再提供覆盖整个区域的蓝色背景。它只负责放置分栏组件、加载态和与工作结束相关的替代状态。

### 分栏组件

`StatusCockpit` 是两个 Panel 的共同布局容器：

- `status-cockpit__work` 是蓝色倒计时 Panel。
- `status-cockpit__reaction` 是橙色精神状态 Panel。
- 桌面端采用约 `2.15fr / 1fr` 的列比例。
- 两列等高，使用同等级边框、阴影与圆角语言。
- 两块内容分别裁切在自己的 Panel 内，不允许跨列覆盖。

### 蓝色倒计时 Panel

蓝色背景、白色倒计时数字、黄色 LIVE 标签和进度条保持现有视觉语言。`WorkCountdownBanner` 在自己的 Panel 中使用完整高度，其标题、时间、进度和 `WorkhorseRunner` 都以蓝色 Panel 为定位边界。

加载态、加载错误、下班确认、加班状态和下班完成状态仍占用蓝色 Panel；它们不会改变右侧精神状态 Panel 的独立边界。

### 橙色精神状态 Panel

精神状态区域始终使用独立橙色背景。顶部展示“当前精神档位”和状态选择控件；主体展示巨型情绪字、吉祥物与黄色文案框。

巨型字作为橙色 Panel 内的背景装饰，吉祥物和文案位于其前景。所有元素受橙色 Panel 的 `overflow` 和内部安全间距约束，不进入蓝色区域，也不遮挡倒计时主视觉。

## 响应式布局

- 宽度大于 860px：保持约 68/32 的横向等高分栏。
- 宽度不大于 860px：改为单列堆叠，蓝色倒计时在上、橙色精神状态在下。
- 移动端分别调整两个 Panel 的最小高度和字号，但不恢复覆盖式布局。

## 数据与交互

本次只调整布局和样式，不改变状态数据流：

- `StatusCockpit` 继续通过 `useWorkStatus` 获取当前状态。
- `WorkStatusPanel` 继续负责切换精神状态。
- `getWorkStatusReaction` 继续决定巨型字、吉祥物、动画与文案。
- `WorkCountdownBanner` 继续接收倒计时和工作计划数据。

状态加载失败或暂不可用时，仅在橙色 Panel 内展示现有骨架态；倒计时区域仍可独立工作。

## 测试与验收

组件测试验证：

- `StatusCockpit` 同时渲染蓝色工作 Panel 和橙色精神状态 Panel。
- 两个 Panel 是同一布局容器下的兄弟节点。
- 当前状态、吉祥物和文案仍位于精神状态 Panel 内。
- 倒计时内容仍位于工作 Panel 内。

样式契约测试或源文件断言验证：

- 桌面端列比例为约 68/32。
- 两个 Panel 分别拥有蓝色和橙色背景。
- 外层 `today-page__stage` 不再使用蓝色背景包裹两块区域。
- 860px 以下切换为蓝上橙下的单列布局。

人工验收验证：

- 两块 Panel 等高、边框基线对齐。
- 橙色内容不进入蓝色区域。
- 倒计时主视觉不被精神状态元素遮挡。
- 今日待办与工作时间编辑器的下方 Dashboard 布局保持不变。

## 非目标

- 不改变倒计时、工作进度或精神状态的业务逻辑。
- 不调整今日待办和工作时间编辑器布局。
- 不更换现有配色、字体、吉祥物素材或状态文案。
- 不新增状态类型或交互入口。
