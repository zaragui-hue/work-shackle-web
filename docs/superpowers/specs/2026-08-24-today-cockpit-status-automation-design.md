# Work Shackle 今日页驾驶舱与状态自动化设计

## 目标

把当前今日页从多张并列、含义重叠的卡片重组为一条清晰的信息主线：先回答“我现在是什么状态”，再回答“接下来要做什么”。同时让工位小闹钟成为工作状态的自动化入口，并让顶部状态、今日页表情包和嘲讽文案同步响应。

## 当前问题

- 顶部“人还在线”是静态装饰，无法反映真实工作状态。
- 黑色主舞台中的状态选择器、蓝色“今日精神广播”和顶部状态在重复表达同一件事。
- 下班倒计时、精神状态、任务、下班时间和提醒以相同视觉权重并列，缺少阅读顺序。
- “今日工位使用证”和“工位小闹钟”挤在一张长卡中，常用信息与低频编辑混杂。
- 票据尾部、重复标题和说明文案增加了噪音，没有帮助用户完成操作。

## 页面结构：单线驾驶舱

### 1. 状态驾驶舱

页面首屏只保留一个主舞台，合并现有 `WorkStatusPanel`、`WorkCountdownBanner` 和 `WorkdayBrief` 的职责：

- 左侧展示下班倒计时、上班进度和上下班时间。
- 右侧展示当前工作状态、状态对应的表情包和一句嘲讽文案。
- 状态可以手动切换，但入口收敛为紧凑控件，不再单独占据一块状态面板。
- 下班确认、加班计时和已下班状态继续在同一主舞台中替换倒计时内容。

### 2. 今日任务

任务区成为页面唯一主内容，按“逾期 / 即将到点 / 今天要做”保持现有业务分组和操作能力。

- 保留新建任务、打开任务详情、空状态、加载和错误恢复。
- 删除票据尾部及不帮助决策的重复装饰文案。
- 午餐提醒等临时信息以紧凑插条出现，不抢占独立大卡。

### 3. 工位控制台

右侧窄栏集中承载工具型信息：

- 上半部分显示并编辑今日下班时间。
- 下半部分显示工位小闹钟时间线，直接展示时间、名称、目标状态和启用状态。
- 新增、删除、文案和目标状态等低频编辑默认收起，避免页面持续展开成长表单。

## 状态单一来源

引入应用壳层级的工作状态控制器，作为顶部状态、今日页驾驶舱和提醒自动化的共同数据源。它负责：

- 读取固定状态列表与当前状态。
- 执行手动或自动状态切换。
- 暴露加载、切换中和错误状态。
- 在切换成功后同时更新所有消费者，避免各组件分别请求造成不同步。

顶部静态“人还在线”改为动态状态胶囊。例如显示 `🏃 被需求追杀`、`🐟 摸鱼中` 或 `🍚 午餐中`。“人还在线”只保留为状态系统的总称和无障碍说明，不再作为重复的可见卡片标签。

## 小闹钟自动切换

提醒到点后的数据流为：

1. 提醒管理器识别当前应触发的提醒。
2. 立即调用共享状态控制器，切换到提醒配置的目标状态。
3. 成功后标记提醒已处理，并同步顶部状态与驾驶舱内容。
4. 页面显示一条短暂提示，说明已切换到什么状态。

自动切换不再要求用户确认。为避免重复触发，同一提醒在同一工作日只尝试一次；切换失败时保留原状态、记录本次已尝试，并显示带“重试”动作的错误提示，不进入无限重试循环。

## 表情包与文案系统

表情系统采用“原创打工马主体 + 网络梗图表达语言”的混搭方式：

- 以已有原创打工马素材为核心，补充会议、插单、摸鱼、吃饭、午休、发呆和准备下班等反应。
- 使用网络表情包常见的贴纸边框、大字字幕、对话框、速度线和局部 Emoji 强化情绪。
- 不直接搬运来源不明的网络图片，不依赖远程资源。
- 每个工作状态配置多条短文案和可用反应；文案根据“状态 + 工作日阶段”稳定选择，同一次状态期间不随机跳动。
- 状态切换时允许一次短促的入场反应；其余时间保持静止或轻微循环，并尊重系统的减少动态效果设置。

示例文案：

- 被需求追杀：`需求说不急，只是希望你十分钟前交。`
- 会议中：`麦克风已开，灵魂未接入。`
- 摸鱼中：`正在进行非生产性战略休息。`
- 午餐中：`当前最高优先级：别让外卖凉。`
- 准备下班：`文件正在保存，人已经到电梯口。`

## 组件边界

- `WorkStatusProvider`：共享当前状态、状态列表和切换动作。
- `StatusCockpit`：组合倒计时、当前状态、表情和文案，不直接请求状态数据。
- `WorkStatusSwitcher`：只负责手动选择状态，可嵌入驾驶舱。
- `WorkdayTools`：组合下班时间与提醒时间线，低频编辑可折叠。
- `WorkStatusReaction`：根据状态和工作日阶段解析表情资源与稳定文案。
- `AppShell`：消费共享状态并渲染顶部动态状态胶囊。

现有任务、下班决策、加班和提醒持久化逻辑继续复用，不修改数据库结构。

## 错误、加载与空状态

- 状态首次加载时，顶部显示中性状态点，驾驶舱保留稳定骨架，不闪回静态“人还在线”。
- 状态切换失败时保留原状态，错误提示明确说明失败并提供重试。
- 表情资源缺失时回退到职业假笑打工马，不阻断页面。
- 没有小闹钟时显示一个紧凑的新增入口，不展示大面积空卡。

## 响应式与无障碍

- 宽窗口采用“任务主栏 + 工位控制台窄栏”；状态驾驶舱横跨两栏。
- 窄窗口依次排列状态驾驶舱、任务、工位控制台，阅读顺序保持不变。
- 所有状态切换、折叠和重试操作支持键盘，并有可见焦点。
- 表情包若只表达情绪则对辅助技术隐藏；状态名称和切换结果始终以文本提供。
- 自动切换结果通过非打断式 live region 宣告。

## 测试与验收标准

1. 今日页首屏不再同时出现独立状态栏和“今日精神广播”。
2. 顶部状态、驾驶舱状态、表情和文案在手动或自动切换后保持一致。
3. 小闹钟到点可直接切换目标状态，不弹确认框，同一提醒不会重复触发。
4. 自动切换失败时保留原状态，显示可重试错误且不会循环请求。
5. 下班倒计时、下班决策、加班、任务操作、午餐提醒和下班时间编辑行为不回归。
6. 常见桌面与窄窗口下信息顺序清楚，无横向溢出。
7. 状态映射、稳定文案、自动切换、共享状态同步和主要渲染分支均有自动化测试。

## 非目标

- 不改变固定工作状态的业务含义或数据库表结构。
- 不把任务、DDL 或日历系统重新设计为全新模型。
- 不接入第三方表情包平台或在线图片搜索。
- 不让系统根据任务内容猜测并擅自改变状态；只有用户操作和已配置的小闹钟可以触发切换。
