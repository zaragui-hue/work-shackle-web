# 今日待办紧凑任务卡片设计

## 背景

今日待办卡片当前将任务内容和“任务管理”拆成上下两个区域，正式任务还会展示较大的时间压力印章。卡片因此过高，横向空间利用不足；任务已有的备注字段没有出现在卡片中；抽屉里的紧急程度也无法在列表中查看或修改。

## 目标

- 将普通今日任务卡片高度控制在约 76–88px，同时保留核心时间信息。
- 在卡片中展示一行任务备注，没有备注时不保留空白。
- 将抽屉中的紧急程度移到卡片，并允许直接切换 1–5 级。
- 将现有主状态操作合并进卡片顶部，删除独立的任务管理底栏。
- 保持卡片详情入口、状态更新、逾期表达和移动端可用性。

## 方案选择

采用“A · 紧凑两层”布局：标题、紧急程度和主状态位于第一行；备注位于第二行；时间、DDL、接头人和细进度条构成紧凑信息区。该方案比右侧操作列更适合窄窗口，也比极限单行布局更能保留长标题和备注的辨识度。

不新增自定义业务标签，也不修改任务数据结构。卡片上的“标签”仅指现有紧急程度和主状态。

## 卡片信息结构

卡片从上到下包含：

1. 标题行：任务标题、紧急程度标签、主状态标签。
2. 备注行：仅在 `task.note` 去除首尾空白后非空时渲染，单行截断。
3. 时间信息行：按现有任务类型展示剩余或逾期时间、计划时间、DDL 和接头人。
4. 时间进度条：继续使用现有进度计算，但降低为细条。

普通卡片目标高度为 76–88px。标题默认单行截断，备注也使用单行截断；完整内容仍可通过点击非操作区域打开详情抽屉查看。历史欠账和已完成任务复用同一结构，根据数据可用性省略不适用字段。

卡片左侧色条与紧急程度同步，既提供快速扫视能力，也避免只依赖文字标签。紧急程度标签本身始终显示文字，因此颜色不是唯一信息来源。

## 紧急程度操作

紧急程度标签位于标题行。点击后展开包含 1–5 级的紧凑菜单，当前级别带有选中状态。选择一个新级别后立即更新卡片展示并调用现有任务更新接口持久化 `priority`。

更新期间禁用当前任务的紧急程度入口，防止重复请求。保存成功后刷新今日任务集合；保存失败时恢复原级别，在今日任务区域显示明确错误，并允许再次操作。选择当前级别只关闭菜单，不发送请求。

紧急程度入口位于详情按钮之外，点击标签或菜单不会打开详情抽屉。菜单支持键盘打开、方向选择、确认和关闭，并提供与任务标题关联的无障碍名称。

## 主状态操作

删除卡片底部独立的“任务管理”区域。非终态任务的主状态选择器改为标题行中的紧凑标签控件；已完成和已取消任务显示只读状态标签。

主状态继续沿用现有状态转换逻辑：普通状态调用更新接口，完成和取消调用各自的专用动作。状态控件同样位于详情按钮之外，操作时不会触发详情抽屉。

## 时间压力与逾期表达

正式任务不再使用约 66px 高的大型时间压力印章。时间压力由短文案、进度条颜色和必要的紧凑状态标识表达，避免和任务自身的紧急程度混淆。

历史欠账继续保留逾期时长和逾期等级，但印章缩为与标签体系一致的紧凑样式。自动开工播报仍可临时出现，不计入普通静态卡片高度。

## 组件与数据流

- `TodayTaskCard` 负责紧凑结构、备注、紧急程度菜单和操作隔离。
- `TodayTaskBoard` 将紧急程度与主状态回调、忙碌任务标识传给每张卡片。
- `TodayPage` 调用现有 `updateTask({ id, priority })` 保存紧急程度，刷新今日任务数据，并复用任务操作错误区域。
- 任务详情抽屉继续保留紧急程度字段，使列表快捷操作与完整编辑入口保持一致。
- 不新增数据库字段、迁移或 Tauri 命令。

紧急程度保存和主状态保存分别维护忙碌任务标识，确保一个任务的操作不会禁用整个列表。刷新后的后端数据是最终展示依据。

## 响应式与无障碍

桌面端保持标题行的三个主要元素同排。窄屏优先保留紧急程度和主状态入口，标题可截断；备注与时间信息继续各占一行，不将操作入口推入独立底栏。

所有可点击标签具有可见键盘焦点。紧急程度菜单使用按钮和菜单项语义，当前值不仅通过颜色表达。尊重现有的减少动态效果设置，不为菜单加入非必要动画。

## 错误与边界

- 空白备注不渲染备注行。
- 极长标题、备注、接头人和时间信息均在各自行内截断，不撑高卡片。
- 无 DDL 的任务不展示 DDL 或依赖 DDL 的进度信息。
- 选择当前紧急程度不发起更新。
- 保存紧急程度失败时回滚视觉状态并保留原任务数据。
- 紧急程度或主状态更新期间只禁用对应任务的相关控件。
- 已完成、已取消任务的主状态只读；其紧急程度是否可编辑遵循现有详情抽屉规则，终态任务保持只读。

## 测试与验收

- 有备注的卡片展示去除首尾空白后的一行备注；无备注的卡片不产生空行。
- 标题、紧急程度和主状态处于同一顶部信息区，卡片不再渲染“任务管理”底栏。
- 点击紧急程度可看到 1–5 级选项，选择新级别调用任务更新并刷新列表。
- 点击紧急程度或主状态不会打开详情；点击标题、备注或时间区域会打开详情。
- 紧急程度保存失败会恢复原值并显示错误。
- 正式任务不再渲染大型时间压力印章，逾期任务仍有紧凑且可读的逾期表达。
- 桌面与窄屏布局均不产生横向溢出，普通卡片在真实内容下达到约 76–88px 的目标高度。
- 相关组件测试、页面交互测试、完整前端测试和生产构建通过。
