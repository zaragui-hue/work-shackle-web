# 今日待办克制赛博卡片设计

## 目标

重塑今日待办列表，使卡片更潮流、更有情绪，但不牺牲阅读效率。用户必须能快速看到任务标题、备注、紧急程度、主状态、剩余时间和时间进度；跨日逾期任务必须独立进入“昨日烂尾现场”，且不得与上方今日列表重复。

## 视觉方向

主题是“克制工位警报”：页面像一张正在运行的工位事故单，而不是满屏霓虹的赛博海报。

- 纸张底色：沿用现有 `--color-paper-raised`，维持产品整体质感。
- 结构墨色：沿用 `--color-anchor` / `--color-ink`，承担边框、标题和交互轮廓。
- 正常进度蓝：沿用 `--color-stage`，只表示时间尚未越过截止线。
- 逾期警报红：沿用 `--color-danger`，只用于逾期轨道、超时标记和高危状态。
- 紧急提示黄：沿用 `--color-signal`，用于优先级和状态选择器的小面积强调。

字体继续使用项目现有字体变量。任务标题放大到约 16–17px，备注约 12–13px，标签和辅助信息约 10–11px。唯一的视觉记忆点是“倒计时信号标记沿时间进度轨道移动”；不使用连续倾斜、大面积霓虹、重复贴纸或多层阴影。

## 页面文案

- 卡片标题：`今天这些破事 / 先狠狠干掉`
- 工具栏提示：`⚠ 别让 DDL 先动手`
- 新建按钮：`＋ 再塞一件`
- 逾期分区：`昨日烂尾现场`
- 逾期数量：`N 笔旧账`

文案保持疯感，但每一处只承担一个信息任务。逾期分区标题下不再显示“跨过零点……”等解释句。

## 今日任务卡片

卡片保持紧凑，阅读顺序固定为：

1. 标题、紧急程度、主状态。
2. 单行备注；空备注不占位。
3. 时间消耗、计划时间、DDL 和接头人。
4. 时间进度轨道。

“距离爆炸”不再作为右侧独立色块。它以小型高对比标记悬浮在进度条当前百分比位置，显示剩余时间；进度变化时标记跟随移动。标记靠近两端时通过 CSS 收边，不得溢出卡片。无有效计划时间或截止时间时不渲染轨道和标记。

## 昨日烂尾现场

逾期集合是独立列表。渲染前以前端任务 ID 做兜底去重：凡已在 `overdueTasks` 中的任务，不再出现在 `formalTasks`。同一任务在页面只出现一次。

逾期卡片保留标题、备注、紧急程度、主状态、接头人和原始时间信息。逾期时间轨道使用红色满格，不再把原完成百分比作为填充宽度；满格表达“已经越过截止线”。超时标记固定停在轨道末端，显示 `已经炸了` 与逾期时长。轨道下方保留原 DDL。

严重程度按现有逾期时长等级呈现，并增加疯感但可执行的提示：

- 24 小时内：`尸体还热。五分钟能回就快回，不行就延期，别装死。`
- 24–72 小时：`它已经在工位上扎根了。建议优先处理，今天别再养它。`
- 72 小时以上：`这活已经获得永久工位。要么重排，要么结束，别再供着。`

卡片保留现有紧急程度和状态直接切换能力。延期通过打开任务详情修改 DDL；状态选择器继续支持处理、暂停和结束等动作，不额外堆叠一整排重复按钮，避免再次变花。

## 状态与边界

- 加载、错误、空状态、完成任务折叠区保持现有行为。
- 完成或取消任务仍只读。
- 优先级与状态保存失败时沿用现有错误提示和回滚行为。
- 移动端标题与备注允许收缩，倒计时标记缩短文案但仍显示数字。
- 所有交互保留可见键盘焦点；进度条提供正确的 `progressbar` 语义。
- 尊重 `prefers-reduced-motion`，轨道标记与填充不做动画。

## 验收标准

1. 同一任务同时出现在正式与逾期输入集合时，页面只在“昨日烂尾现场”渲染一次。
2. 普通任务的倒计时标记位于进度条当前节点，并随时间进度变化。
3. 逾期任务轨道视觉和无障碍数值均为 100%，超时标记停在右端。
4. 逾期分区无解释性副标题，标题显示旧账数量。
5. 任务标题、备注、优先级和状态在桌面与 390px 宽度均清晰、无重叠。
6. 页面使用克制的黑、蓝、红、黄体系，不出现连续倾斜与大面积装饰噪声。
