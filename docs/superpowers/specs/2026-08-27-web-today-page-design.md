# Web 今日页设计

## 目标

在现有 Work Shackle 仓库中新增一个相对独立的 Web 子项目，将桌面 App 的「今日」页面和相关能力转化为电脑浏览器版本。Web 端在用户选择的本地文件夹中保存数据，不需要服务器、账号或云同步。

## 独立性边界

- Web 端位于独立的 `web/` 子项目。
- 不修改现有桌面 App 的 `src/`、`src-tauri/`、SQLite、Tauri 命令、提醒机制或打包配置。
- Web 端不调用 Tauri，也不读写桌面 App 的数据库。
- Web 端可以在初次开发时复刻已确认的 App 视觉和行为，但之后不会跟随 App 更新。
- 只有在用户明确发出 Web 端修改指令时，才将已确认的 App 功能转化到 Web 端。
- 本次不抽取双端共享组件，不建立自动同步机制。

## 支持范围

第一版只支持电脑浏览器，正式支持最新版 Chrome 和 Edge，建议视口宽度不低于 1024px。小于该宽度时页面应保持可读并给出提示，不开发完整的手机布局。

本次不实现独立任务页和设置页，也不显示它们的导航入口。今日页中必需的任务和工作时间操作仍然保留。

## 页面和行为

Web 端首页复刻现有 App 的今日页，包括：

- 品牌页头、当前工作状态与今日状态入口。
- 上下班倒计时、工作状态切换、状态文案和吉祥物反馈。
- 当天下班时间调整。
- 工作过程提醒的新增、编辑、开关和到点自动切换状态。
- 午休提醒、正常下班确认、开始和结束加班。
- 今日正式任务、逾期任务、已完成任务和自动开始提示。
- 新建、查看、编辑、完成、取消、延期及优先级调整。
- DDL 进度和页面打开期间的提醒。

浏览器通知需要用户明确授权。页面打开期间运行倒计时和定时检查；页面或浏览器关闭后不保证触发提醒。

## 本地数据

首次进入时，Web 端要求用户选择数据文件夹，并在其中创建 `work-shackle-web.json`。文件包含数据结构版本、任务、任务提醒、延期记录、工作状态记录、排班、午休、加班、下班确认和页面提醒配置。

文件夹句柄可保存在当前网站的 IndexedDB 中，用于下次打开时尝试恢复访问。浏览器仍可能要求用户再次授权。Web 端不得因权限失效而创建空数据覆盖原文件。

初次创建数据时，使用与当前 App 一致的默认工作时间、状态选项、提示文案和提醒规则。

## 启动与数据流

1. Web 端检查 File System Access API 兼容性。
2. 尝试恢复上次保存的文件夹句柄和权限。
3. 无句柄或需重新授权时，引导用户选择原数据文件夹。
4. 读取并校验 `work-shackle-web.json`。
5. 根据当前日期和时间计算今日任务、倒计时、午休、加班和提醒状态。
6. 用户操作先通过业务规则校验，再更新内存状态并立即写入文件。
7. 页面持续检查日期变化，跨过零点时重新计算新工作日，不删除历史记录。

## 数据安全和恢复

- 每次修改先完整校验数据，再写入主文件。
- 主文件写入前，将上一份有效数据写入 `work-shackle-web.backup.json`。
- 每天首次修改时生成 `backups/work-shackle-web-YYYY-MM-DD.json`，默认保留最近 30 天。
- 页面提供「立即备份」，下载一份独立数据文件。
- 主文件损坏时停止写入，可从上一版本或每日备份恢复。
- 数据版本较旧时先备份再迁移；数据来自未来版本时拒绝覆盖并提示升级 Web 应用。
- 保存失败时明确标记当前更改「尚未保存」，保留页面内存状态并允许重试。
- 文件夹移动或删除时要求用户重新定位，不自动重置历史。

## 错误处理

- 不支持 File System Access API：阻止进入业务页并提示使用最新 Chrome 或 Edge。
- 权限失效：提示重新选择原文件夹。
- 数据校验失败：进入只读恢复界面，禁止覆盖主文件。
- 业务输入无效：在相应表单中显示可执行的中文提示。
- 通知权限被拒绝：保留页面内提醒，不影响任务和时间数据。

## 测试和验收

- 单元测试覆盖今日任务分类、自动开始、任务状态、延期、优先级和 DDL 计算。
- 单元测试覆盖上下班倒计时、午休、加班、跨天和提醒触发。
- 数据层测试覆盖初始化、读写、校验、版本迁移、备份、恢复和写入失败。
- 页面测试覆盖新建、编辑、完成、取消、延期和重新打开后的数据恢复。
- 在 Chrome 和 Edge 中人工验证文件夹授权、刷新、浏览器重启、通知授权和备份恢复。
- 与当前 App 今日页做视觉和关键交互对照，但不因此修改 App 端。

## 不在本次范围

- 任务页、历史页或日历页。
- 设置页。
- 手机和平板完整适配。
- 用户账号、服务端数据库、云同步或多端实时同步。
- 页面关闭后仍持续运行的系统级提醒。
- App 与 Web 之间的代码共享或自动功能同步。
