# 工位控制台紧凑时间选择器设计

## 目标

修复工位控制台小时、分钟下拉菜单尺寸异常的问题。保留页面上的大号时间展示和修改即保存逻辑，将系统原生长下拉菜单替换为尺寸受控、易于滚动的紧凑数字面板。

## 问题判断

当前小时和分钟使用原生 `select`，控件本身采用大号数字字体。macOS 会将字号和选项数量带入系统下拉菜单；分钟列表又包含 60 项，因此点击后出现远大于控件和窗口预期的菜单。

仅缩小 `option` 字号无法稳定控制不同 WebView 和操作系统中的系统菜单尺寸，所以需要把“大数字显示”与“紧凑选择面板”分离。

## 交互设计

- 时间继续拆分为小时和分钟两个触发按钮，中间保留冒号。
- 点击小时按钮，打开小时面板；点击分钟按钮，打开分钟面板。同一时间只允许打开一个面板。
- 面板宽度与对应数字按钮一致，最大高度为 200px，内容超出时在面板内部滚动。
- 小时列显示 `00`–`23`，分钟列显示 `00`–`59`，选项采用正常界面字号，不继承大数字字号。
- 当前值使用荧光绿底和粗体标识；面板打开时自动将当前值滚动到可视区域。
- 选择一个值后立即关闭面板，并复用现有校验、即时保存、保存失败回滚逻辑。
- 点击面板外部或按 `Escape` 关闭，不修改当前值。
- 保存期间禁用两个触发按钮并关闭面板，避免并发保存。

## 视觉设计

整体继续沿用 Work Shackle 的“工位控制台”语言，但把视觉力量集中在时间本身，不让弹层抢占页面。

- 大数字仍使用数据字体和等宽数字，保持当前信息优先级。
- 时间容器从整块刺眼色板调整为深色控制台底座；荧光绿用于当前值、聚焦状态和少量信号提示。
- 小时和分钟按钮拥有独立但紧邻的点击区域，悬停和键盘聚焦状态清晰。
- 弹层使用浅色纸面、硬边框和小幅硬阴影，与应用既有“事故单 / 票据”语言一致。
- 面板不使用全屏遮罩，也不改变控制台及下方提醒区域的布局。

## 组件边界

新增一个仅服务于时分选择的紧凑选择组件：

- 接收当前值、候选值、无障碍标签、禁用状态和选择回调；
- 自己管理开关、外部点击、键盘关闭和当前项滚动；
- 不负责时间合法性、后端保存或错误文案。

`WorkScheduleEditor` 继续负责：

- 拼接小时与分钟；
- 调用现有时间校验；
- 发起即时保存；
- 保存失败时恢复当前生效时间并显示错误。

这样可以把弹层行为与业务保存流程隔离，避免为单一时分场景扩展成全局日期时间组件。

## 无障碍与键盘

- 触发器暴露当前值、展开状态以及对应面板关系。
- 面板和选项使用可识别的列表框语义，当前项明确标记。
- `Enter` 或空格打开面板；方向键移动候选项；`Enter` 确认；`Escape` 关闭并将焦点还给触发器。
- `Tab` 关闭面板并按正常页面顺序离开控件，不制造焦点陷阱。
- 所有聚焦状态保持高对比度，并尊重现有的减少动态效果设置。

## 响应式与边界情况

- 在控制台窄栏和 420px 以下窗口中，面板不得超出卡片或视口；必要时向内侧对齐。
- 面板高度固定受控，小时选项较少时也不扩大。
- 保存失败、时间校验失败、排班从外部刷新时，任何已打开面板都关闭，并以 `schedule.effectiveEnd` 为准同步显示。
- 快速重复点击或保存期间操作不会创建并发请求。

## 验证标准

- 点击小时或分钟后，弹层最大高度为 200px，不再出现占据大半窗口的系统菜单。
- 小时、分钟均能选择并组合成正确的 `HH:mm` 值。
- 当前值在面板打开时可见并高亮。
- 选择后仍立即保存；校验或保存失败时仍回滚并显示错误。
- 点击外部和按 `Escape` 能关闭；键盘可以完成打开、移动、确认和退出。
- 桌面宽屏、控制台窄栏及 420px 以下布局均无溢出。
- 现有 `WorkScheduleEditor` 测试继续通过，并补充紧凑面板的交互测试。

## 非目标

- 不改变工作时间的数据结构、后端命令或保存策略。
- 不改造设置页、提醒编辑器和任务日期时间选择器。
- 不新增时间步长、快捷时间或日期选择能力。
