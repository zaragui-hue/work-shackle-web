# 应用显示名称改为「精神状态事务所」设计

## 目标

将 Work Shackle 桌面应用所有面向用户的应用名称统一为「精神状态事务所」，同时保持现有安装身份、用户数据和自动更新链路兼容。

## 修改范围

- Tauri `productName` 改为「精神状态事务所」，用于 macOS、Windows 的应用与安装包显示名称。
- 主窗口标题改为「精神状态事务所」。
- Web 页面标题改为「精神状态事务所」。
- Rust 包描述中的用户可见英文旧名称改为中文新名称。
- 如构建产物名称由 `productName` 自动生成，则接受对应安装包名称同步变化。

## 明确保留

- 保留 Tauri identifier：`com.workshackle.app`。
- 保留 npm 包名和 Rust crate 名：`work-shackle`。
- 保留 GitHub 仓库及自动更新地址。
- 保留现有本地存储键、事件名、工作目录识别文案和数据目录。
- 不修改版本号、业务功能、页面视觉设计或更新逻辑。

## 兼容性

保留原有 identifier，确保操作系统继续将新版识别为同一应用。保留内部包名与存储键，避免用户设置、任务数据和更新机制因显示名称变化而迁移或失效。

## 验证

- 增加或更新名称契约测试，校验 Tauri 产品名、窗口标题和 HTML 标题一致。
- 运行完整前端测试与生产构建。
- 运行 Tauri 配置/原生编译检查。
- 检查差异，确认内部 identifier、更新地址和存储键未被修改。

## 发布说明

本次仅完成本地代码变更，不提交、不推送、不发布。当前已安装应用不会立即改名；待未来构建并安装新版本后，系统中的应用名称才会显示为「精神状态事务所」。
