# 倒计时系统警报标题区设计

## 背景

今日页倒计时舞台的轮播标题使用超大字号和约 `8em` 的固定最大宽度，同时允许在任意字符处换行。面对“下班节点尚未渲染，先维持人类在线状态”这类长文案时，标题会在左侧挤成多行字墙，而右侧除“班味”徽章外留下大面积无效空白。

## 目标

- 让标题使用倒计时舞台的横向空间，长文案通常保持一至两行，极长文案最多三行。
- 保留并强化 Work Shackle「一本正经发布荒诞工位通知」的反讽审美。
- 保持倒计时数字为面板最高信息层级，不修改倒计时、轮播文案或工作进度业务逻辑。
- 在桌面、窄桌面和手机尺寸下避免文字重叠、单字断行和水平滚动。

## 已确认方向

采用“黄色系统警报带”方案。蓝色舞台保持为稳定底色，黄色横条成为标题区唯一的高强度视觉动作。横条承载完整轮播文案，并通过小号系统编号制造企业通知与荒诞内容之间的反差。

## 版式与视觉

- 顶部保留 `LIVE / 距离释放` 与右上角旋转的“班味”徽章。
- 标题区域改为横向警报带，使用 `var(--color-signal)` 背景、`var(--color-anchor)` 文字和上下墨色粗边框。
- 警报带内增加 `SYSTEM NOTICE / SHIFT RELEASE` 小号等宽标签，用作真实的结构信息，不参与业务状态表达。
- 标题使用紧凑高字重、正常中文词间换行和自适应字号；移除 `max-width: 8em` 与 `overflow-wrap: anywhere`。
- 桌面端警报带允许约一度轻微倾斜和轻量横向溢出，形成贴上去的通知条效果；它是该区域唯一新增的倾斜元素。
- 倒计时与进度条结构、位置和层级保持不变，防止标题改造扩大顶部面板高度。

## 响应式行为

- 宽屏与窄桌面：警报带使用可用宽度，标题字号随容器收缩，最多显示三行。
- 手机：取消警报带倾斜和横向放大，减小内边距与字号；徽章继续位于标题区域顶部，不与正文重叠。
- `prefers-reduced-motion` 下继续停用现有脉冲动画；本次不新增持续动画。

## 组件边界

- `WorkCountdownBanner.tsx`：为标题增加系统通知标签与警报带语义容器；倒计时拆分和工作进度数据流保持不变。
- `WorkCountdownBanner.css`：重建标题区布局、警报带样式与响应式规则。
- `WorkCountdownBanner.test.tsx`：验证系统通知标签、完整长文案和现有倒计时信息同时渲染。

## 可访问性

- 警报带是视觉结构，不改变标题的 `h2` 语义。
- 系统通知标签使用可理解文本，但不冒充错误或实时告警。
- 黄色背景与墨色文字沿用现有高对比令牌。
- 装饰性倾斜不改变点击区域；该区域本身没有新增交互。

## 验收标准

1. 截图中的长文案不再挤成左侧字墙，右侧空间被标题警报带有效使用。
2. 标题没有单字强制断行，桌面端通常为一至两行，最长轮播文案不超过三行。
3. 倒计时数字、单位、进度条、跑马和“班味”徽章均完整可见，面板高度不增加。
4. 760px 以下单列布局与 520px 以下手机样式无重叠或水平滚动。
5. 组件测试、相关布局测试、全量前端测试和生产构建通过。
6. 在实际页面截图中，黄色警报带醒目但不压过主倒计时。

## 非目标

- 不改轮播文案内容、轮播时机或倒计时计算。
- 不抽取关键词，不为不同文案维护手工断句规则。
- 不新增图片、在线字体、持续跑马灯或闪烁动画。
- 不重排右侧精神状态面板。
