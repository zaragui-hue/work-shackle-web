# 设置页面板精简设计

## 目标

精简“设置”页面，删除“今日工作时间”面板和“日历忙碌状态”配置面板，同时保持今日页的工作时间调整能力和任务日历的忙碌状态展示不变。

## 界面调整

- “工作时间”区域只保留“默认工作时间”表单。
- 删除“今日工作时间”卡片，包括当前生效时间、“仅修改今天”和“恢复默认”。
- 删除由“仅修改今天”打开的弹窗。
- 设置页不再渲染“日历忙碌状态”配置面板。
- 修改设置页顶部说明，移除“忙碌程度”相关表述，使说明与剩余功能一致。

## 逻辑清理

- 从 `SettingsPage` 删除只服务于今日临时时间面板的状态、表单、事件处理器、接口导入和弹窗依赖。
- `getWorkSchedule` 继续用于加载默认工作时间，但页面不再保存完整 `WorkSchedule` 状态。
- 保存默认工作时间后，只用返回结果刷新默认时间表单。
- 保留底层今日临时时间接口和今日页的 `WorkScheduleEditor`，不改变今日页行为。
- 仅移除 `BusyRuleSection` 在设置页的导入和渲染。保留忙碌规则组件、表单、服务、Hook 和日历展示逻辑，以便日历继续读取现有或默认规则。

## 错误与加载状态

- 设置页原有默认工作时间、午餐时间的加载和保存错误处理保持不变。
- 删除今日临时时间专属错误状态，因为对应入口已不存在。
- 忙碌规则配置面板不再发起独立加载请求；任务日历仍按原逻辑加载忙碌规则。

## 测试

- 增加设置页结构测试，确认“今日工作时间”和“日历忙碌状态”不出现。
- 确认“默认工作时间”“午餐时间”和状态文案设置仍出现。
- 验证设置页源码不再导入或渲染 `BusyRuleSection`，也不再包含今日临时调整弹窗逻辑。
- 运行完整测试套件和生产构建，确认今日页及任务日历没有回归。
