# 精神状态事务所顶部栏吸顶设计

## 目标

让包含“精神状态事务所”、当前精神状态和主导航的整条顶部栏在页面滚动时保持可见。

## 方案

- 对 `.ws-shell__brand` 使用 `position: sticky` 和 `top: 0`。
- 保持顶部栏原有尺寸和响应式布局，不在吸顶后缩小。
- 设置足够高的层级，避免页面卡片和普通弹出内容覆盖顶部栏。
- 保留黄色背景，增加底部阴影以区分滚动内容。
- 将 `.ws-shell` 的 `overflow: hidden` 改为 `overflow: clip`。这样继续裁切圆角视觉边界，但不会创建阻止 sticky 生效的滚动容器。
- 正式 App 与设计预览页共享同一套 AppShell 样式，效果同步生效。

## 响应式行为

- 桌面端吸顶整条横向顶部栏。
- 窄窗口继续使用现有上下两行布局，整块一起吸顶。
- 不改变 Logo、标题、当前状态和导航的现有尺寸。

## 验证

- 添加样式契约测试，检查 `sticky`、`top: 0`、层级和外壳裁切方式。
- 运行相关测试、全量前端测试和生产构建。

## 不在范围

- 滚动后缩小顶部栏。
- 使用 JavaScript 监听滚动。
- 改变导航结构或文案。
